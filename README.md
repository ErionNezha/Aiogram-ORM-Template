# aiogram3 + Tortoise ORM Template

Template profesional boti aiogram 3 me Tortoise ORM — struktura gati për projekte serioze Telegram.

`Python` `aiogram` `Tortoise ORM`

## 🚀 Live Demo
Hape **`index.html`** në browser — demo-ja ekzekutohet direkt, pa instalime.
Nëse repo është publikuar me GitHub Pages: `https://erionnezha.github.io/Aiogram-ORM-Template/`

## 📝 Kodi Burim
Kodi i plotë është në dosjen [`original/`](original/) dhe shfaqet krahas demo-s live në `index.html`.

## ▶️ Ekzekutimi origjinal
Kopjo .env.template → .env, plotëso BOT_TOKEN, `pip install -r requirements.txt`, `python main.py`.
